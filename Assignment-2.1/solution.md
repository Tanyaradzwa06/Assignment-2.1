Assignment 2.1 — First HTML Page
Aim

To create a basic webpage using HTML with a title, main heading, subheadings, and comments.

Theory

HTML stands for HyperText Markup Language. It is the standard markup language used to create and structure webpages. HTML uses different elements and tags to display text, headings, paragraphs, images, links, and other content in a web browser.

An HTML document begins with the <!DOCTYPE html> declaration, which tells the browser that the document uses HTML5. The <html> element is the root element of the webpage. The <head> element contains information about the document, such as its title, while the <body> element contains the content displayed on the webpage.

The <title> tag defines the title shown in the browser tab. HTML provides six levels of headings, from <h1> to <h6>, which help organize content into a clear hierarchy. The <h1> tag is generally used for the main heading, while smaller heading tags are used for subheadings.

HTML comments are written using <!-- comment -->. They help developers explain the code and are not displayed as webpage content. Proper indentation makes HTML code easier to read and maintain.

After writing the HTML code, the file is saved as index.html and opened in a web browser to verify that the webpage displays correctly.

Objectives
To understand the basic structure of an HTML document.
To learn how to use HTML tags and headings.
To understand the purpose of HTML comments.
To create and view a simple webpage in a browser.
Conclusion

Successfully created a basic HTML webpage using the required document structure, page title, main heading, subheadings, and HTML comments. The webpage was opened in a browser to verify its output.
